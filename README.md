# Mechanix RPG

RPG-мод для Minecraft Forge 1.20.1 в стиле аниме и манхвы.

- 14 рас (у каждой пассивка и способность на клавишу R), выбор при первом входе
- Уровни, 4 характеристики, 5 классов, 25 заклинаний, мана
- Монстры и боссы: Король гоблинов, Варлорд орков, Лич (3 фазы, боссбар)
- Руды: мифрил, звёздное железо, кровавый камень, кристаллы маны
- Башня мага, лагерь гоблинов, руины орков
- Книга-гайд внутри игры

## Клавиши
K: меню персонажа. R: способность расы. Z X C V: заклинания.

## Команды (для операторов)
`/mechanix level|xp|points|race|class|mana|reset`

## Сборка
Сборка идёт в GitHub Actions (вкладка Actions, workflow `main.yml`, артефакт `mechanix-jar`).
Перед сборкой скрипт `tools/gen_resources.py` создаёт текстуры, модели, рецепты, лут, генерацию мира и переводы.
Чтобы поменять эти ресурсы, правьте скрипт. Свою текстуру можно положить в
`src/main/resources/assets/mechanix/textures/...`, готовые PNG скрипт не перезаписывает.

## Настройки
`config/mechanix-common.toml` (максимальный уровень, опыт, урон заклинаний, структуры, боссы и т. д.).
