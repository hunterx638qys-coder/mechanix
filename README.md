Тестовый мод для **Minecraft Forge 1.20.1** с набором новых игровых механик: телепорт, жильная добыча,
вампиризм, плиты-ускорители и другое. Подходит как песочница и как пример структуры Forge-мода
(регистрация предметов/блоков/эффектов, события, команды, конфиг).

> **Замена `YOUR_USER`:** после создания репозитория замените его в бейдже выше.

## Механики

### Предметы
| Предмет | Действие |
|---|---|
| Посох телепортации | ПКМ — телепорт вперёд по взгляду |
| Жильная кирка | Присед + добыча руды ломает всю жилу |
| Амулет-магнит | ПКМ вкл/выкл, притягивает предметы вокруг |
| Жезл бури | ПКМ — молния в блок до 48 клеток |
| Клык вампира | ПКМ — эффект «Вампиризм» (удары лечат) на 2 мин |
| Песочные часы времени | ПКМ — переключить день/ночь |

### Блоки
| Блок | Действие |
|---|---|
| Стартовая площадка | Подбрасывает вперёд и вверх, без урона от падения (присед — пропустить) |
| Плита скорости | Скорость IV |
| Плита исцеления | Регенерация II |
| Хрупкий блок | Рассыпается через секунду после наступания |

### Мир и игрок
- **Рубка деревьев** — присед + топор по бревну
- **Удачная добыча** — 8% шанс бонусного дропа с руды
- **Вампиризм** — новый эффект; клык выпадает из монстров (5%)
- **Координаты смерти** в чат
- **Команды:** `/mechanix sethome`, `/mechanix home`, `/mechanix heal` (только операторы)

Все механики отключаются и настраиваются в `config/mechanix-common.toml`.

## Установка

1. Установите [Forge 1.20.1](https://files.minecraftforge.net/) (47.3.0 или новее)
2. Скачайте jar из раздела [Releases](../../releases)
3. Положите в папку `mods`

## Сборка из исходников

Нужен JDK 17.

```bash
# Gradle wrapper не хранится в репозитории — создайте его один раз:
gradle wrapper --gradle-version 8.1.1

./gradlew build        # jar появится в build/libs/
./gradlew runClient    # запуск тестового клиента
```

Или скопируйте `gradlew`, `gradlew.bat` и папку `gradle/` из официального Forge MDK 1.20.1.
В IntelliJ IDEA достаточно открыть `build.gradle` как проект.

## Структура

```
src/main/java/com/example/mechanix/
├── MechanixMod.java        точка входа
├── MechanixConfig.java     настройки
├── registry/               регистрация блоков, предметов, эффектов, вкладки
├── block/                  логика блоков
├── item/                   логика предметов
├── effect/                 эффекты
├── event/ModEvents.java    игровые события (деревья, вампиризм, дроп...)
├── command/                команды
└── util/BlockUtil.java     поиск жил/деревьев, добыча с инструментом
src/main/resources/         модели, текстуры, рецепты, лут, lang
```
